ABOUT ME

一个把教学经验变成产品与增长方案的应届生

我是何春江，中南财经政法大学刑事司法学院2027届本科生。我的专业是侦查学（法庭科学方向）——一个天然训练「证据意识」与「逻辑拆解」的交叉学科。

过去一年半，我在武汉前程高考教育中心担任高三化学、生物一对一主讲，辅导30余名学生，同时把AI深度融入教学：从Prompt设计到多模态内容生产，从错题分析到个性化训练方案。单科最高提分30分，家长续费率100%。

这段经历让我确信：AI的价值不在技术本身，而在「用对场景、解决真问题」。于是我把方法论产品化，独立完成了「错题星」——一款AI高中理科个性化学习助手的完整设计，包括MRD/BRD/PRD三份文档与可交互Demo。

此外，我在商务、运营与增长上同样有实战：商务助理实习推动采购成本下降12%；校团委副部长统筹12场大型活动、管理10人团队；三创赛负责人带队用1600份问卷拿下校级一等奖。

为什么学侦查学，做 AI / 商业？ 侦查学训练的是证据意识和逻辑拆解——先定位问题、再找证据、再下结论。这正是产品需求分析（定义问题）与顾问式销售（诊断痛点）的核心能力。跨学科训练让我能快速迁移新领域知识，GPA 3.92（前10%）验证了学习转化能力。

AI CAPABILITY

AI 能力与 Prompt 案例库

不是「会用AI工具」，而是能设计「稳定可用的AI能力」——下面是错题星中的六大AI模块与真实Prompt案例。

MODULE 01

OCR 后处理

对拍照识别结果做结构化纠错与格式规整，提升题目录入准确率。

MODULE 02

考点分析

将题目映射到高中理科知识点体系，输出考点标签与难度评估。

MODULE 03

错因分析

基于自研错因分类体系（概念/计算/审题/思维），输出可行动的错因诊断。

MODULE 04

错题聚类

跨题聚合，输出「氧离子化合价标注错误率80%」式细粒度漏洞报告。

MODULE 05

同类题生成

基础/中档/拔高三级难度分层的变式题生成与题库检索策略。

MODULE 06

多模态生成

思维导图、图解、课件等可视化内容的生产链路与质量校验。

目标：判断学生这道题为什么错，从「对/错」升级为「错在哪、为什么、怎么补」。
角色
你是一位有20年经验的高中化学教师，熟悉高考命题规律与学生的常见错误模式。
任务 + 输出格式
分析下面这道错题，按JSON输出：{错因分类, 具体描述, 涉及知识点, 补救建议}。错因分类只能从【概念不清/计算失误/审题偏差/思维方法】中选。
约束
① 描述必须具体到这道题，禁止套话；② 补救建议要可执行，给出一个具体学习动作；③ 若题目信息不足，输出"需补充"，不要猜测。
效果与沉淀从粗粒度「概念错误」升级为「氧离子化合价标注时正负号写反」，并可自动归类、追踪同知识点错题的重错率变化。
目标：把一道题映射到知识点体系，支撑「错题聚类 → 漏洞报告」链路。
角色
你是一名教研专家，熟悉高中化学「物质结构与性质」「化学反应原理」等模块的知识点分层。
任务 + 输出格式
识别该题考查的知识点，按JSON输出：{一级知识点, 二级知识点, 考点标签[], 难度(基础/中档/拔高), 考查能力}。
约束
① 知识点必须来自给定体系表，禁止自创标签；② 同一题可多标签，按主次排序；③ 难度按高考真题标准评估。
效果与沉淀保证聚类维度统一（同一知识点用同一标签），避免「同义不同词」导致漏洞报告失真。
目标：生成难度分层的同类变式题，让每道错题都有对应的巩固训练。
角色
你是一位高中化学命题教师，擅长基于真题改编变式题。
任务 + 输出格式
基于原题考查的知识点，生成3道变式题，分别对应基础/中档/拔高，按JSON输出：{难度, 题干, 选项或答案, 解析, 考查点}。
约束
① 必须覆盖原题知识点，但情境或数值要改变；② 拔高题要综合2个以上知识点；③ 每题给出完整解析与答案。
效果与沉淀「题库检索 + AI生成」双通道：优先高质量真题，题库空缺时由AI补位，并纳入人工质检。
目标：生成家长/学生都能看懂的漏洞报告，把「10道错题」翻译成「哪里弱、怎么补」。
角色
你是一位教育顾问，擅长把数据分析结果翻译成家长能听懂、学生能执行的建议。
任务 + 输出格式
基于错题聚类数据，生成结构化报告：{本周漏洞TOP3, 每项错误率, 原因解读, 学习建议, 下周目标}。
约束
① 语言通俗，禁止专业黑话；② 建议必须具体（如「每天15分钟专项训练」而非「加强练习」）；③ 只陈述数据支持的事实，不夸大。
效果与沉淀报告页将「碎片化刷题」转化为「系统性补漏」，支撑续费与口碑——这是续费率100%的关键一环。
